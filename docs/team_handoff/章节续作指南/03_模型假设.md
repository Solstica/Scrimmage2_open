# 模型假设续作指南

唯一正文源：
```text
modules/12_assumptions/paper/assumptions.tex
```

canonical branch：
```text
feature/assumption-paper-a
```

初始化：
```bash
git fetch origin --prune
git switch -c task/model/assumptions-<topic>-YYYYMMDD origin/feature/assumption-paper-a
```

当前排版：
```latex
enumerate + itemsep=0.3ex
```

规则：
- 只写对模型成立必要且可解释的假设；
- 不把结论写成假设；
- 不额外加顶级 `\section`；
- 若假设变化导致 Q2/Q3 参数或公式变化，必须通知编程手并把依赖结果标记 STALE。

提交：
```text
model(assumptions): ...
```
或纯文字：
```text
docs(assumptions): ...
```
