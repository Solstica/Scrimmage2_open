## 总体结论

这个实现包的**工程组织是清楚的**，但理论文档、实际代码和结果解释之间没有对齐。

最关键的判断是：

[
\boxed{
\text{文档写的是 Sellmeier–Drude–Fresnel 模型，}
\quad
\text{代码实现的是固定折射率的 FFT 谐波拟合。}
}
]

所以当前结果 (7.40\pm0.12,\mu\mathrm m) 不能直接作为我们刚锁定的范文复现结果。它甚至不是包内谐波模型自身的最优解。

实现代码见：[solve_q1_q2.py](sandbox:/mnt/data/modules_extracted/solve_q1_q2.py)

# 2. 代码实际执行的模型

代码没有执行 `q1.txt` 和 `q2.txt` 中写的 Sellmeier–Drude–Fresnel 模型。

实际流程是：

## 2.1 固定波段

截取

[
2500\sim3300\ \mathrm{cm^{-1}}.
]

这一步符合实际光谱，也与范文 A 一致，可以保留。

---

## 2.2 平滑去基线

使用 1001 点、三阶 Savitzky–Golay 平滑估计基线：

[
z(\sigma)=R(\sigma)-B(\sigma).
]

---

## 2.3 FFT 估计条纹频率

对去基线信号做零填充 FFT，提取主频率：

[
f_\theta
========

\arg\max_f
\left|
\mathcal F[z_\theta]
\right|.
]

结果为：

[
f_{10^\circ}=0.0041441,
\qquad
f_{15^\circ}=0.0040053
\quad
(\mathrm{cycles/cm^{-1}}).
]

---

## 2.4 固定折射率换算厚度

代码直接规定

[
n_{\mathrm{eff}}=2.72,
]

然后利用

[
f_\theta
========

2\times10^{-4}d
\sqrt{
n_{\mathrm{eff}}^2-\sin^2\theta
}
]

计算厚度：

[
\boxed{
d_\theta
========

\frac{f_\theta}
{2\times10^{-4}
\sqrt{
n_{\mathrm{eff}}^2-\sin^2\theta
}}
}.
]

得到：

[
d_{10^\circ}=7.6333\ \mu\mathrm m,
]

[
d_{15^\circ}=7.3962\ \mu\mathrm m.
]

---

## 2.5 用谐波回归拟合反射率

固定频率后，拟合

[
\boxed{
R(\sigma)
=========

a_0+a_1t+a_2t^2
+b\cos(2\pi f\sigma)
+c\sin(2\pi f\sigma).
}
]

其中：

* (a_0+a_1t+a_2t^2) 是二次基线；
* (b,c) 表示条纹振幅与相位。

这是一套**谐波回归模型**，没有使用两个界面的 Fresnel 系数。

---

## 2.6 所谓“双角度联合拟合”

代码将厚度限制在

[
d\in
[\min(d_{10},d_{15}),\max(d_{10},d_{15})]
=========================================

[7.3962,7.6333]
]

内，搜索使两个角度谐波拟合 RMSE 平方和最小的厚度。

最后得到

[
d_{\mathrm{joint}}
==================

7.396176\ \mu\mathrm m.
]

它与 15°单角度结果完全相同。

| Drude 载流子修正           | 没有 (N)           |
| 拟合载流子浓度 (N)           | 没有任何载流子参数        |

# 4. 当前数值结果存在一个确定的算法错误

我使用包内原有的 `fit_trace` 目标函数，取消“联合厚度必须位于两个 FFT 厚度之间”的人为约束，重新扫描了

[
5\le d\le10\ \mu\mathrm m.
]

得到：

[
d_{10^\circ}^{\mathrm{harmonic}}
\approx7.232\ \mu\mathrm m,
]

[
d_{15^\circ}^{\mathrm{harmonic}}
\approx7.238\ \mu\mathrm m,
]

双角度联合最优为

[
\boxed{
d_{\mathrm{joint}}^{\mathrm{harmonic}}
\approx7.235\ \mu\mathrm m.
}
]

而当前代码报告

[
7.3962\ \mu\mathrm m.
]

两者差约

[
0.161\ \mu\mathrm m.
]

联合残差平方和由当前结果的约

[
9.84\times10^{-7}
]

下降到

[
7.28\times10^{-7},
]

降低约

[
\boxed{26.0%}.
]

所以当前联合结果不是目标函数的真实最优值。原因是代码强制规定：

```python
left = estimates.min()
right = estimates.max()
```

真实最优值位于该区间之外，搜索被卡在左边界，最终“联合结果”恰好等于 15°结果。

---

# 5. FFT 单角度估计本身也不可靠

拟合波段宽度只有约

[
800\ \mathrm{cm^{-1}},
]

条纹周期约为

[
240\sim250\ \mathrm{cm^{-1}},
]

所以整个波段只有约

[
3.2\sim3.3
]

个完整周期。

用三个多周期的信号做 FFT 主频估计，频率分辨能力有限。代码虽然使用 32 倍零填充，但零填充只能使频谱曲线显示得更密，不能增加真实频率信息。

这解释了为什么：

* FFT 换算得到 (7.633) 和 (7.396)；
* 直接最小化同一谐波模型却得到约 (7.232) 和 (7.238)。

其中 10°的 FFT 偏差尤其明显。

此外，1001 点平滑窗口对应约

[
482\ \mathrm{cm^{-1}},
]

接近两个条纹周期。它可能同时影响基线和条纹主频，必须通过窗口敏感性验证，不能固定后直接使用。

# 6. 当前不确定度没有统计依据

代码定义：

[
u_d
===

# \frac{|d_{10}-d_{15}|}{2}

0.1186\ \mu\mathrm m,
]

然后报告：

[
7.40\pm0.12\ \mu\mathrm m.
]

这只是两个 FFT 估计差值的一半，不能视为置信区间或标准不确定度。

而且两个单角度 FFT 结果本身就不是谐波回归最优解，因此用它们的差异计算不确定度没有意义。

当前实现没有：

* 参数协方差；
* Bootstrap；
* 初值稳定性；
* 波段敏感性；
* 折射率敏感性；
* 有效折射率 (2.72) 的来源和误差。

因此推荐结果一栏需要删除，直到重算完成。

# 9. 哪些内容必须重写

## 9.1 `solve_q1_q2.py` 的模型内核

需要真正实现：

[
n_2(\lambda,N)
]

的 Sellmeier–Drude 折射率，

[
r_{12,u},t_{12,u},r_{23,u},t_{21,u}
]

的 Fresnel 系数，以及

[
r_u
===

r_{12,u}
+
t_{12,u}r_{23,u}t_{21,u}
e^{-i\Delta\varphi}.
]

然后分别对 10°、15°进行非线性最小二乘。

## 9.2 单角度主结果

输出真正的：

[
d_{10},\qquad d_{15},
]

以及各自的 Sellmeier–Drude–Fresnel 拟合曲线和指标。

## 9.3 主厚度

按照范文 A：

[
\bar d
======

\frac{d_{10}+d_{15}}2.
]

## 9.4 联合拟合

联合拟合放在可靠性验证中：

[
J_{\mathrm{joint}}=J_{10}+J_{15}.
]

不再人为限制联合厚度必须位于两个独立结果之间。

## 9.5 结果汇总

至少增加：

* RMSE；
* MAPE；
* (R^2)；
* 参数是否达到边界；
* 多初值稳定性；
* 联合厚度与平均厚度差异。
