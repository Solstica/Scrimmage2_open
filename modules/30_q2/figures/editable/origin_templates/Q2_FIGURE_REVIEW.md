适用分支：`feature/q2-paper-a`。本文件供编程手重绘 Origin 图及论文手更新正文时使用。

正式口径：10°、15°分别独立反演，厚度为 7.8566 μm 与 7.6230 μm，最终算术平均 7.7398 μm；正式拟合窗口为 2500--3300 cm^-1；Q2 存在多个干涉级次局部极小值，不能解释为所有初值收敛到同一点。

## 0. 总体流程图口径

正式流程固定为：

`附件1、2 -> 百分数转小数并截取2500--3300 cm^-1 -> 10°、15°两条独立反演支路 -> 每角度90组阶段一初值 -> 固定Sellmeier参数的三参数有界粗拟合 -> 近似重复候选去重 -> 保留前8个候选 -> 释放7个Sellmeier参数进行完整十参数精修 -> 每角度取最低RMSE候选 -> 得到d_10与d_15 -> 等权算术平均 -> 拟合指标、双角度一致性与多盆地残差验证 -> 输出d_SiC=7.7398 μm`。

硬性要求：
- 删除“共享参数联合拟合”“联合目标函数决定正式厚度”等旧逻辑；
- 两角度可以在版面上并列，但优化阶段不得画成信息交换或共享参数；
- 不需要“是否联合拟合”的判断菱形；
- 最终输出只保留当前正式结果 7.7398 μm；
- 图中不得出现 `PAPER_A`、开发阶段命名或旧结果。

## 1. 正文插图尺寸规范

Origin 中各单图 Layer 尺寸统一，因此 LaTeX 中按“小图等尺寸”原则插入：

- 两张同规格小图横向并列：每张 `0.44\textwidth`，两张合计约 `0.88\textwidth`，中间用 `\hfill`；
- 已在 Origin 中合成的双面板：整体 `0.88\textwidth`；
- 单独一张同规格 Origin 数据图：`0.44\textwidth`；
- 流程图、机理示意图不属于同规格 Origin 数据图，可按可读性使用 `0.88\textwidth`，但不再使用 0.94、0.96、0.70、0.50 等零散宽度；
- 同一类图在全文保持完全一致的宽度，不通过 LaTeX 二次缩放制造大小差异。

正文优先形成两种视觉单元：`0.88\textwidth` 的双图/宽图，以及 `0.44\textwidth` 的单图。
