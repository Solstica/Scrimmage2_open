# 2. 10°：主要问题是“碰撞率几乎不敏感”，而不是四列严重共线

参数顺序：

\[
(d,n_3,\log_{10}N,\log_{10}\Gamma_e).
\]

## 原始 Jacobian 奇异值

\[
(14.2251,\ 4.92453,\ 0.437310,\ 1.64239\times10^{-4}).
\]

原始条件数：

\[
\kappa(J)\approx 8.66\times10^4.
\]

但原始条件数受参数尺度影响，因此不能单独解释。

## 列范数

| 参数 | \(\|J_j\|_2\) |
|---|---:|
| 厚度 \(d\) | 14.2136 |
| 衬底折射率 \(n_3\) | 4.92138 |
| \(\log N\) | 0.742431 |
| \(\log\Gamma_e\) | \(2.40082\times10^{-4}\) |

碰撞率方向的绝对灵敏度已经极低。

## 相对尺度灵敏度

| 参数 | 相对灵敏度 |
|---|---:|
| \(d\) | **0.716802** |
| \(n_3\) | 0.271587 |
| \(\log N\) | 0.0115275 |
| \(\log\Gamma_e\) | \(3.72769\times10^{-6}\) |

厚度相对灵敏度约为：
- \(\log N\) 的 **62 倍**；
- \(\log\Gamma_e\) 的约 **1.9×10^5 倍**。

## 列归一化 SVD

奇异值：

\[
(1.34744,\ 1.31153,\ 0.523399,\ 0.436273),
\]

条件数仅：

\[
\kappa_{\mathrm{corr}}\approx3.09.
\]

这说明：

> 10° 的超大 raw condition number 主要由参数敏感度幅值悬殊造成，而不是四个归一化参数方向完全共线。

当前 \(\log\Gamma_e\) 落在下边界，是与其近乎零灵敏度一致的。

\]

原始条件数：

\[
\kappa(J)\approx5.75\times10^8.

## 列范数

| 参数 | \(\|J_j\|_2\) |
|---|---:|

## 相对尺度灵敏度

| 参数 | 相对灵敏度 |
|---|---:|
| \(d\) | **0.911651** |
| \(n_3\) | 0.269045 |
| \(\log N\) | \(2.92984\times10^{-9}\) |
| \(\log\Gamma_e\) | \(2.69633\times10^{-9}\) |

即厚度对反射率的局部影响比两个载流子相关参数高约 **3×10^8** 个量级比。

## 最弱右奇异方向权重

列归一化后最弱方向的绝对权重约为：

| 参数 | 权重 |
|---|---:|
| \(d\) | **0.0069** |
| \(n_3\) | 0.1741 |
| \(\log N\) | **0.4606** |
| \(\log\Gamma_e\) | **0.3584** |

因此最弱方向中：

\[
w_N+w_\Gamma\approx81.9\%.
\]

而厚度只占约：

\[
0.69\%.
\]

这正是非常直接的可辨识性证据：

> 15° 的局部退化方向主要由载流子浓度与碰撞率构成，厚度几乎不参与最弱方向。

# 4. 15° 参数局部相关性也非常强

局部相关矩阵的主要项约为：

\[
\rho(n_3,\log N)\approx-0.99865,
\]

\[
\rho(n_3,\log\Gamma_e)\approx0.99391,
\]

\[
\rho(\log N,\log\Gamma_e)\approx-0.99829.
\]

因此 15° 下 \(n_3,N,\Gamma_e\) 存在极强局部耦合。

与此同时：

\[
\rho(d,n_3)\approx-0.0096,
\]

厚度与衬底折射率局部相关很弱。

这进一步支持“厚度作为主要测量量，而附属载流子参数不作材料学定量解释”。

# 5. 两角度综合判断

## 厚度
两个角度的相对灵敏度均最高：

- 10°：0.7168；
- 15°：0.9117。

所以厚度是当前四参数模型中最强的光谱敏感方向。

## \(n_3\)
次于厚度，仍保持明显灵敏度：

- 10°：0.2716；
- 15°：0.2690。

## \(N,\Gamma_e\)
可辨识性明显弱：

- 10°：\(N\) 尚有少量作用，但 \(\Gamma_e\) 几乎无敏感性；
- 15°：二者几乎都无局部敏感性，并且互相/与 \(n_3\) 高度相关。

因此当前正文关于：

> 不将载流子浓度和碰撞率作为材料测量结论

可以得到数学加强。

# 6. 多初值结果也支持“厚度盆地稳定、附属参数不稳定”

说明 10° 的最佳厚度附近有很近的竞争盆地，但二者厚度仅差约：

## 15°

- 5 个收敛到 \(d\approx3.187520\)；

因此 15° 的厚度盆地在当前 6 组确定性初值下反而具有较好的吸引稳定性，虽然 \(N,\Gamma_e\) 本身落在边界并不可辨。

# 7. 对论文模型表达的直接升级

现在可以把原来的：

> 部分参数触边，因此附属参数可辨识性不足。

升级成更有数学依据的：

> 在两个入射角的最优Airy解处，本文构造反射率残差关于 \(d,n_3,\log_{10}N,\log_{10}\Gamma_e\) 的局部Jacobian，并进行尺度化奇异值分解。结果表明，厚度在两个角度均具有最高局部相对灵敏度；15°下最弱奇异方向约81.9%的权重来自 \(N\) 与 \(\Gamma_e\)，且二者与 \(n_3\) 的局部相关系数绝对值接近1。结合载流子参数触边现象，可知附属参数存在明显弱可辨识与耦合，而厚度并非主要退化方向。因此本文保留四参数Airy厚度反演，但不将边界处载流子参数作材料学定量解释。

这段结论目前由实际计算支持。

# 8. 对“是否释放更多振子背景参数”的判断

本次四参数诊断已经给出一个非常明确的信号：

- 10°已有一个近乎无敏感性的 \(\Gamma_e\) 方向；
- 15°已有两个近乎无敏感性的载流子方向；
- 15°同时存在严重参数相关。

因此从逆问题条件性看，继续释放 \(A_j,\lambda_j,\Gamma_j,\varepsilon_\infty\) 很可能只会增加弱可辨方向。

所以当前“固定振子背景参数”的选择获得了明显支持。

下一步如要进一步强化，可做 **11参数扩展 Jacobian 前向敏感性**，但不必重新做11参数拟合。
