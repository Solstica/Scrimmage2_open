# 摘要续作指南

## 唯一正文源
```text
modules/00_abstract/paper/abstract.tex
```

canonical branch：
```text
feature/abstract
```

全文 wrapper：
```text
paper/abstract_content.tex
```
**wrapper 不是正文源。**

## 开始
```bash
git fetch origin --prune
git switch -c task/paper/abstract-<topic>-YYYYMMDD origin/feature/abstract
```

## 当前结构要求
必须保留：
```text
% <ABS:INTRO>
% <ABS:Q1>
% <ABS:Q2>
% <ABS:Q3>
% <ABS:KEYWORDS>
```

不得在模块内加入：
```latex
\begin{abstract}
\end{abstract}
```

## 数值红线
Q2：7.8566、7.6230、7.7398 μm。
Q3：3.2480、3.1875、3.2178 μm。

摘要只能写已 FROZEN 的结果。

## 提交
```text
docs(abstract): ...
```

若只是公共摘要宽度/字体问题，不在本分支改，转 `feature/paper-common-final`。
