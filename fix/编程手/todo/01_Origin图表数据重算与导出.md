# Origin 图表数据重算与导出

本任务不是重新使用 Python 画一套替代图。

流程为：

最终 PAPER_A 模型
→ Python 重算数据
→ 导出 CSV/XLSX
→ Origin 原工程替换数据
→ 导出最终 PNG/PDF

必须继续复用人工设计好的 Origin 图形模板。

程序输出必须使用当前冻结结果：

Q2：
10° = 7.8566 μm
15° = 7.6230 μm
SiC = 7.7398 μm

Q3：
10° = 3.2480 μm
15° = 3.1875 μm
Si = 3.2178 μm

若旧 Origin 表中包含旧参数、旧模型比较或旧厚度，必须重新生成数据表，不得只修改图中文字。
