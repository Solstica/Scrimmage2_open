# Q2 第二轮技术正确性与范文贴合审查

状态：已按审查意见直接修改 `feature/q2-paper-a` 正文、算法流程与伪代码。

## 本轮发现并修正

1. **“吸引域”表述过强。** 正式求解器并没有做严格盆地聚类，而是先运行 90 组阶段一初值，再按 `(round(d,3), round(logN,2))` 去重并保留前 8 个候选。因此正文已改为“候选局部极小解/数值去重”，不把该步骤包装成严格吸引域识别。
2. **载流子浓度对数的量纲问题。** 原文直接写 `log10 N`。现定义 `q_N=log10[N/(1 cm^-3)]`，与代码中的 `log10_carrier_cm3` 数值一致。
3. **参数设置可复现性不足。** 已加入正式边界、阶段一初值和 Sellmeier 登记参数，明确 90 组初值来自 `10×3×3`。
4. **等权平均理由不足。** 已补充：两光谱来自同一晶圆、拟合质量处于同一量级，且不额外引入角度权重，因此沿参考解法采用两独立厚度等权平均；平均值不是一次新拟合，因此不定义 RMSE/MAPE/R²。
5. **验证指标与范文贴合度不足。** 在原 RMSE、R² 基础上补入 MAPE 定义与结果：10° 为 0.2680%，15° 为 0.2978%。
6. **半极差易被误读为不确定度。** 已明确 `0.1168 μm` 只描述两个独立角度结果的离散程度，不是统计置信区间或仪器测量不确定度。
7. **边界参数表述过泛。** 已明确两个角度的载流子浓度对数均触及下边界附近，且多个 Sellmeier 扰动参数达到 ±5% 边界，因此这些附属参数不作材料常数解释。
8. **波段选择论证不够闭环。** 已把 2500--3300 cm^-1 与 Q1 弱吸收实折射率近似直接关联，并引用参考解法；同时把 10°/15° 原始光谱旧版图先插入正文占位。
9. **求解流程与代码不完全一一对应。** `q2_algorithm_flow.tex` 与 `q2_pseudocode.txt` 已改成“90 初值 → 按 `(d,q_N)` 数值去重 → 前 8 候选 → 完整十参数精修 → 两独立厚度平均”。
