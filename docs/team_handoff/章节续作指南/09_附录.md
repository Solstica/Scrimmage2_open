# 附录续作指南

唯一正文源：
```text
modules/70_appendix/paper/appendix_code.tex
```

canonical branch：
```text
feature/paper-common-final
```

初始化：
```bash
git fetch origin --prune
git switch -c task/paper/appendix-<topic>-YYYYMMDD origin/feature/paper-common-final
```

附录应登记当前真实代码入口，例如：
```text
shared/code/materials.py
shared/code/optics.py
modules/30_q2/code/
modules/40_q3/code/
scripts/test_physics.py
scripts/verify_paper_a_results.py
scripts/build_previews.ps1
scripts/build_paper.ps1
```

禁止：
- 把旧附录代码当最新实现；
- 在正文复制大量代码；
- 登记不存在的脚本。

修改后先核对实际文件路径。
