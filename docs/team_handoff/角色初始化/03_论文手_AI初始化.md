## 2. 初始化

```bash
git fetch origin --prune

git log --graph --decorate --oneline --all -n 20
```

先读：
```text

fix/论文手/todo/
```

再读：
```text
docs/team_handoff/章节续作指南/<目标章节>.md
```

## 3. 开任务分支

格式：
```text
task/paper/<module>-<topic>-YYYYMMDD
```

例如：
```bash
git switch -c task/paper/q2-results-wording-20260807 origin/feature/q2-paper-a
```

不要从 `main` 开正文任务分支。
不要从 `feature/paper_liu` 开。
不要从旧 `document.tex` 开。

## 5. 字体和公共格式

当前公共模板已经迁回：
- 中文：Fandol 字体族；
- 英文：Times New Roman；
- 符号表采用 `tabularx` 等公共依赖。

因此：
- 不要在每个模块里重新 `\setCJKmainfont`；
- 不要把旧 `modules/paper汇总/document.tex` 的整套导言区复制回来；
- 公共字体/页边距/标题层级只在 `feature/paper-common-final` 修改。

## 6. 1.png / 2.png / 3.png 和新 Origin 图为什么没显示

**不是删除。**

它们被保留为待更新模板：
- Q1：`.../q1_flow_reference.png`
- Q2：`.../origin_templates/reference_png/2.png` 与 01–14 图
- Q3：`.../origin_templates/reference_png/q3_flow_reference.png` 与 Origin projects

暂未进入正文的原因：
- 图中数据或逻辑仍对应旧路线；
- 必须先由建模手确认逻辑；
- 编程手重算数据；
- 你再在 Origin 中替换数据/标签并导出最终图。

禁止：
- 直接把旧 PNG 引回正文；
- 只把图中文字改成 7.7398 / 3.2178；
- 用 Python 临时重画替代人工 Origin 版式；
- 把旧图删掉。

最终导出时改成规范名：
```text
q1_model_flow.png
q2_model_flow.png
q3_model_flow.png
q2_residual_ecdf.png
...
```

## 7. 模块正文结构规则

模块内部不要写：
```latex
\documentclass
\begin{document}
\end{document}
\section{问题一...}
```

顶级章节标题由全文/preview 入口负责。

摘要：
- 保留 `% <ABS:...>` 注释槽；
- 不在 `abstract.tex` 内再套 `\begin{abstract}`；
- 注释槽不会显示在 PDF 中，不得为了“干净”删除。

---

## 8. 论文手禁止事项

- 禁止新建总 `document.tex` 作为正文源；
- 禁止把多个模块复制到一个文件再改；
- 禁止直接编辑 wrapper 来修改章节内容；
- 禁止改 frozen 结果数字；
- 禁止根据旧 Origin 图反推模型；
- 禁止整合 `feature/paper` / `feature/paper_liu`；
- 禁止直接 push `main`；
- 禁止把不确定的图先引用进正文“以后再说”。

---

## 9. 提交前

至少运行：
```bash
python scripts/check_writing_quality.py
powershell -ExecutionPolicy Bypass -File ./scripts/build_previews.ps1
powershell -ExecutionPolicy Bypass -File ./scripts/build_paper.ps1
git diff --check
git status -sb
```

若正文涉及模型/数值，再额外运行：
```bash
python scripts/verify_paper_a_results.py
```

完成后把对应任务从 `fix/论文手/todo/` 移到 `done/`，记录 commit、PDF 和仍需人工检查的位置。
