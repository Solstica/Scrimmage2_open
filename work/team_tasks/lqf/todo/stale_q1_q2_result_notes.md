# 一、问题一的结果

问题一没有独立的数值厚度结果，其成果是建立正演模型：

[
(\sigma,i,d,N,n_3,\text{Sellmeier参数})
\longrightarrow
R_{\mathrm{th}}(\sigma,i).
]

具体包含：

[
n_2^2(\lambda,N)
================

A+
\sum_{j=1}^{3}
\frac{B_j\lambda^2}{\lambda^2-C_j}
----------------------------------

\frac{Ne^2\lambda_m^2}
{4\pi^2c^2\varepsilon_0m^*},
]

[
\Phi
====

4\pi\times10^{-4}
\sigma d n_2\cos\gamma,
]

[
\rho_u
======

r_{12}^{(u)}
+
t_{12}^{(u)}r_{23}^{(u)}t_{21}^{(u)}
e^{-i\Phi},
\qquad u=s,p,
]

[
R_{\mathrm{th}}
===============

\frac{|\rho_s|^2+|\rho_p|^2}{2}.
]

当前程序确实实现了：

* 三项 Sellmeier 色散；
* 固定有效质量的 Drude 修正；
* s、p 两种偏振；
* 两束 Fresnel 振幅叠加；
* (2500\sim3300\ \mathrm{cm^{-1}}) 弱吸收波段；
* 带符号 Fresnel 系数，不额外重复加入固定 (\pi)。

因此，问题一的理论和代码现在基本一致。

当前

不能列出一组边界参数后仍称它们均被准确反演。
