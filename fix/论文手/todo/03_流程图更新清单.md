## Q3

参考资产：`modules/40_q3/figures/editable/origin_templates/reference_png/q3_flow_reference.png`

- 第三束光强比不得作为硅正式模型选择器。

正式流程应拆为两条：

### Si 主路线

`附件3/4 -> 预处理 -> 双振子--Drude复折射率 -> Fresnel系数 -> Airy多光束反射率 -> 10°/15°分别四参数反演 -> 算术平均 -> d_Si = 3.2178 μm`

冻结结果：

- 10°：3.2480 μm；
- 15°：3.1875 μm；
- 最终 Si：3.2178 μm。

### SiC 回溯路线

`读取 Q2 最终参数 -> 计算第三束光强比 η3 -> 与 0.1% 工程参照量级比较 -> 判断高阶光束可忽略 -> 保留 d_SiC = 7.7398 μm`

这里的 0.1% 只用于回溯解释，不控制 Si 正式模型。
