\section{模型假设}

为突出干涉测厚的主要物理机制并保证参数可辨识性，作出以下假设：

\begin{enumerate}[leftmargin=2em,itemsep=0.3ex]
	\item 外延层厚度均匀，上表面和外延层—衬底界面光滑且相互平行，满足薄膜干涉的平行平板条件。
	\item 外延层和衬底在测量区域内横向均匀，载流子浓度不随横向位置变化。
	\item 问题一只考虑两束光：空气—外延层上表面的直接反射光，以及透入外延层后经外延层—衬底界面一次反射、再从上表面透射出的光束，忽略多次内反射。该近似将在问题三中通过第三束光强比进行检验。
	\item 入射光为非偏振光，理论反射率取$s$、$p$两偏振反射率的算术平均。
	\item SiC主反演波段选为$2500\sim3300\ \mathrm{cm^{-1}}$弱吸收区，在该波段内忽略折射率虚部；低波数强吸收区不参与厚度拟合。
	\item 衬底折射率$n_3$在选定的窄波段内近似为常数。
	\item 有效质量$m^*$取文献值，不与载流子浓度$N$同时作为自由参数拟合，以缓解参数冗余。
	\item 硅主反演波段选为$1500\sim3500\ \mathrm{cm^{-1}}$，在该波段内硅存在吸收，使用复折射率描述传播。
	\item 硅背景介电函数参数（$\varepsilon_\infty$、$A_j$、$\lambda_j$、$\Gamma_j$）全部固定为材料文献登记值，不参加优化；只拟合厚度$d$、衬底折射率$n_3$、载流子浓度$N$和自由载流子碰撞频率$\Gamma_e$。
	\item 附件3、4首个约$399.67\ \mathrm{cm^{-1}}$的零反射率点视为文件边界异常，不参与拟合。
	\item 问题三中采用与问题一相同的Fresnel系数定义和传播相位符号，全文统一采用传播因子$e^{-i\widetilde\Phi}$。
	\item 多次往返后的反射光束在探测面上具有足够的空间重合，光源相干长度能够覆盖参与叠加光束之间的光程差，以保证多光束干涉的有效形成。
\end{enumerate}
