# 符号说明续作指南

唯一正文源：
```text
modules/11_notation/paper/notation.tex
```

canonical branch：
```text
feature/notion-paper-a
```

初始化：
```bash
git fetch origin --prune
git switch -c task/paper/notation-<topic>-YYYYMMDD origin/feature/notion-paper-a
```

当前格式：
- `tabularx`
- 彩色表头
- `label{tab:notation}`

公共依赖在：
```text
paper/preamble.tex
```
如果缺包，去 `feature/paper-common-final` 修，不要在符号模块局部重复 `\usepackage`。

规则：
- 不加顶级 `\section{符号说明}`；
- 同一符号跨问含义和单位必须一致；
- 新符号优先在首次出现处定义，只有高频共用符号进入总表。

提交：
```text
docs(notation): ...
```
