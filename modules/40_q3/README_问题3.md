# 问题三：第三束光判据、Airy 多光束拟合与 SiC 回溯

## 运行

在项目根目录执行：

```powershell
python modules\40_q3\code\问题3求解.py --data-dir "D:\qq文件" --project "D:\git数模"
python modules\40_q3\code\整理问题3结果.py
```

第一条命令进行数值求解并写入 `结果\问题3原始结果.json`；第二条命令生成 `Origin数据` 下的中文 XLSX 和 `结果\问题3结果汇总.xlsx`。代码依赖项目根目录的 `shared\code\data_io.py` 和 `shared\code\materials.py`。

## 修正后的模型口径

正式决策链为：第三束光强比判据，决定采用双光束还是 Airy 多光束模型。第三问不再把有限阶 Neumann 展开、AIC 或阶数收敛当作正式证据，也不使用每个角度的经验增益和偏置。

硅固定 293 K 背景折射率和有效质量，只拟合四个物理量：外延层厚度、常数衬底折射率、载流子浓度和自由载流子碰撞参数。程序内部优化 `log10(N)` 和碰撞波数 `log10(Gamma_e/(2πc))`，结果表同时给出 `N (cm^-3)`、碰撞波数和碰撞角频率 `Gamma_e (s^-1)`。正式波段为 `1500–3500 cm^-1`，使用原始反射率，不做经验基线、相位解包或线性标定。

硅分别对 10° 和 15° 做 Airy 拟合，两个单角度厚度的算术平均是问题三主结果；双角度共享参数 Airy 拟合只作一致性验证。双光束结果只作为同一参数口径下的精度对照。

SiC 不重新拟合第三问参数，而是读取第二问正式结果 `modules\outputs\solution_data.json` 的单角度 Sellmeier-Drude 参数，在 `2500–3300 cm^-1` 计算第三束相对第一束光强比。两角均低于 `0.1%` 时保留第二问厚度平均值 `7.7398 μm`。

## 当前结果

运行结果以 `结果\问题3原始结果.json` 和 `结果\问题3结果汇总.xlsx` 为准。硅主结果为两个单角度 Airy 厚度的平均值；联合 Airy 厚度不替代该平均值。正式解释只报告第三束判据、单角度厚度、联合验证和 RMSE，不宣称 Airy 对两个角度均有显著改善。
