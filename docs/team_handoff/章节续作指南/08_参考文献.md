# 参考文献续作指南

唯一正文源：
```text
modules/60_references/paper/references.tex
```

canonical branch：
```text
feature/paper-common-final
```

初始化：
```bash
git fetch origin --prune
git switch -c task/paper/references-<topic>-YYYYMMDD origin/feature/paper-common-final
```

规则：
- 不直接改 `paper/sections/91_references.tex` 的正文；
- 文献必须与正文实际使用的方法/数据对应；
- 禁止为了凑数量加入正文未引用、无法核验的条目；
- 旧总稿里删除/增加过的参考文献不能整体覆盖当前列表。

提交：
```text
docs(references): ...
```
