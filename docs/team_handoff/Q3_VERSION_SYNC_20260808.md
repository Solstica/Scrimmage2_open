## 2. 冻结模型与数值

硅正式模型为 **双振子--Drude 复折射率 + Airy 无限多光束反射率模型**。

- 10°、15°分别独立反演；
- 每个角度采用 6 组确定性初值；
- 正式参数向量为 `(d, n3, qN, qGamma)`；
- 双光束仅允许作为同一组 Airy 最优参数下的前两束截断诊断，不产生第二套正式厚度；
- `eta3` 只用于高阶单束反射量级解释，不作为 Airy / 双光束切换阈值；
- `0.1%` 仅称工程量级参照。

冻结结果：

- Si 10°：`d = 3.2474 μm`；
- Si 15°：`d = 3.1875 μm`；
- Si 等权平均：`d_Si = 3.2175 μm`；
- SiC 回溯保留：`d_SiC = 7.7398 μm`；
- SiC 第三束最大强度比：10°约 `4.852e-7%`，15°约 `4.662e-7%`；
- Jacobian 列归一化条件数：10°约 `3.09`，15°约 `9.95`；
- Airy--双光束同参模型误差传播到厚度的局部量级不超过约 `1.2e-3 μm`。

## 5. 图 19 正式解释

图 19 用于支撑 Jacobian--SVD 局部可辨识性：参数为 `d, n3, log10N, log10Gamma_e`；纵向量为相对灵敏度的对数表达；气泡面积表示最弱右奇异方向中的参数权重；边界活跃参数另作标识。15°最弱方向约 82.1% 权重来自 `qN` 与 `qGamma`，而厚度权重不足 1%，因此主要弱可辨方向来自载流子参数耦合，厚度不是最弱退化方向。

## 6. 15°低 R² 的统一口径

15°固定背景四参数模型对幅值基线和局部谱形仍有明显未解释成分，因此不能把全部光学参数解释为高精度材料常数。厚度主要受连续干涉条纹的相位位置约束，并结合双角度厚度一致性、多初值局部盆地和 Jacobian--SVD 仅将 `d` 作为主要定量输出。

两个角度采用等权平均，不按 RMSE 加权，因为当前 RMSE 同时包含模型系统失配，不能直接解释为厚度估计方差。
