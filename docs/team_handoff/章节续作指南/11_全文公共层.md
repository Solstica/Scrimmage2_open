# 全文公共层续作指南

canonical branch：
```text
feature/paper-common-final
```

公共文件：
```text
paper/main.tex
paper/preamble.tex
paper/cumcmthesis.cls
paper/abstract_content.tex
paper/sections/*
scripts/build_paper.ps1
scripts/build_previews.ps1
fix/
```

当前原则：
- 中文 Fandol；
- 英文 Times New Roman；
- `paper/main.tex` 只做全文装配；
- `paper/sections/*` / `paper/abstract_content.tex` 只做 wrapper；
- 模块正文永远留在 `modules/.../paper/*.tex`。

初始化：
```bash
git fetch origin --prune
git switch -c task/paper/paper-common-<topic>-YYYYMMDD origin/feature/paper-common-final
```

允许修改：
- 字体、页边距、标题格式；
- 通用宏包；
- wrapper 路由；
- 构建脚本；
- 公共任务文档。

禁止：
- 把 Q1/Q2/Q3 正文复制进 `paper/`；
- 新建总 `document.tex` 作为主编辑源；
- 为解决单问排版问题破坏其它模块；
- 直接把历史 `feature/paper` 导言区整块复制回来。

全文验收：
```bash
python -m unittest -v scripts.test_physics
python scripts/verify_paper_a_results.py
python scripts/check_writing_quality.py
powershell -ExecutionPolicy Bypass -File ./scripts/build_paper.ps1
```
