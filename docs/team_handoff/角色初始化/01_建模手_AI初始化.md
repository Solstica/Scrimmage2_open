# 建模手 AI 初始化说明

> 把本文件作为建模手 AI 的第一份上下文。开始任何模型修改前，必须先执行初始化命令并阅读当前 `fix/建模手/todo/`。

## 0. 你的角色边界

你负责：
- 模型逻辑、假设、参数口径、公式关系；
- Q1/Q2/Q3 结果链是否符合当前 PAPER_A；
- 为编程手定义“应该重算什么数据”；
- 为论文手定义“图和文字应该表达什么逻辑”；
- 判断 Origin 旧图哪些可复用版式、哪些数据/逻辑必须更新。

你不负责：
- 擅自重构 LaTeX 公共模板；
- 直接在 `paper/main.tex` 写章节正文；
- 为了排版改模型；
- 为了让结果更接近旧答案而释放参数或换回旧路线；
- 把 `feature/paper` / `feature/paper_liu` 整体合回来。

## 1. 开始前必须确认的当前事实

### Q1
- Sellmeier–Drude–Fresnel 双光束。
- 实折射率算角度；复折射率用于 Fresnel/传播复量。

### Q2
- 10°：7.8566 μm
- 15°：7.6230 μm
- 平均：7.7398 μm
- 两角度分别反演，不使用共享参数联合反演作为正式主路线。

### Q3
- 正式模型始终 Airy。
- 10°：3.2480 μm
- 15°：3.1875 μm
- Si：3.2178 μm
- 第三束比只作解释，不作模型选择阈值。

若 AI 给出 `7.384039`、`3.308745`、“0.1% 阈值决定正式模型”或“共享参数双角度联合拟合”，立即判定为旧路线。

## 2. 初始化命令

```bash
git fetch origin --prune
git status -sb
git log --graph --decorate --oneline --all -n 20
```

先读：
```text

```


## 4. 每个模型任务必须先读什么


```text

```

不要先看旧总稿 `document.tex` 来反推模型。

## 5. 当前图表任务为什么“没显示”

1.png / 2.png / 3.png 和部分 Origin 图没有被删。

它们暂不进正文，是因为：
- Q2 流程图仍带“共享参数联合拟合”旧支路；
- Q3 流程图仍带“阈值选择双光束/Airy”旧逻辑；
- Q2/Q3 若干 Origin 图表中的数据仍来自旧结果；
- Q1 参考流程图需先统一最终术语和公式口径。

你的工作不是删除这些图，而是先给出**每张图的正确模型逻辑和应重算数据字段**。

完成逻辑确认后，把任务要求写清楚给编程手：
```text
输入数据
计算公式
冻结参数
输出列名
单位
允许的容差
图中允许出现的结论
图中禁止出现的旧结论
```

## 6. 建模手禁止事项

- 禁止改 `main`。
- 禁止整合 `feature/paper` 或 `feature/paper_liu`。
- 禁止修改 Origin 图中文字来掩盖数据没重算。
- 禁止只改摘要/结论中的数值而不更新结果链。
- 禁止绕过 `verify_paper_a_results.py`。
- 禁止把模型调整成“更接近范文”而不说明物理依据。
- 禁止把 Q3 第三束比恢复成模型选择阈值。

## 7. 交付给编程手/论文手的格式

每完成一个模型任务，在对应 `fix/建模手/todo/*.md` 文末记录：

```text
最终模型口径：
需要重算的数据：
对应代码入口：
需要更新的 Origin 模板：
最终图应表达：
旧图中必须删除/改写的内容：
冻结数值是否变化：
若变化，哪些章节/结果/图表需要标记 STALE：
```

确认完成后再移动到 `fix/建模手/done/`。
