# B题问题1-2求解与 Origin 数据

## 运行

```powershell
python solve_q1_q2.py --data-dir "D:\qq文件" --output-dir outputs
```

脚本严格按 `q1q2修正.txt` 执行 Sellmeier-Drude-Fresnel 双光束模型：

- 2500-3300 cm^-1 弱吸收波段直接使用原始反射率拟合，不用 FFT 作为正式求解；
- Sellmeier 参数取项目 `shared/code/materials.py` 登记的三项 SiC 参数；
- Drude 项固定有效质量，分别对 10°、15° 做两阶段有界非线性最小二乘；
- 主厚度是两个单角度厚度的算术平均；双角度共享参数拟合不限制厚度区间，只作可靠性验证；
- 输出 RMSE、MAE、MAPE、R²、边界状态、多初值稳定性和联合厚度与平均厚度差异。

## 本轮实际结果

10° 单角度厚度为 `7.8566 微米`，15° 单角度厚度为 `7.6230 微米`，问题二主结果取平均为 `7.7398 微米`。双角度联合验证厚度为 `7.7390 微米`，与平均值相差 `0.0008 微米`，仅作验证，不替换主结果。

两组单角度拟合 RMSE 分别为 `0.000598`、`0.000707`，R² 分别为 `0.9551`、`0.9526`。辅助载流子和部分 Sellmeier 参数达到边界，表明它们在窄波段内辨识度有限，不能当作高精度材料常数解释。

## 输出文件

- `图_附件1_10度原始光谱.xlsx`、`图_附件2_15度原始光谱.xlsx`：原始光谱，一列 X、一列 Y。
- `图_10度实测与模型拟合.xlsx`、`图_15度实测与模型拟合.xlsx`：实测、单角度拟合、联合验证拟合，第一列 X，后三列 Y。
- `图_10度模型拟合残差.xlsx`、`图_15度模型拟合残差.xlsx`：第一列 X，第二列残差 Y。
- `图_双角度厚度对比.xlsx`：10°、15°、单角度平均、联合验证四行厚度数据。
- `总表.xlsx`：结果总表、模型参数、多初值稳定性、厚度结果对比。
- `结果汇总.xlsx`：上述总表和全部 Origin 图表数据。

## Origin 画图建议

1. 原始光谱：选第一列 X、第二列 Y，使用“基本二维-折线图”。
2. 实测与模型拟合：第一列设为 X，后三列设为 Y，使用“折线+符号”；实测用散点，两个模型用实线，横坐标 2500-3300 cm^-1。
3. 残差：第一列 X、第二列 Y，使用“折线图”，在纵坐标 0 处添加水平参考线。
4. 厚度对比：第一列为分类 X、第二列为 Y，使用“柱状图”；主结果看“单角度平均”，联合值仅用作验证标记。
5. 坐标轴可写“波数 (cm^-1)”和“反射率”；字体建议中文微软雅黑、英文和数字 Arial。

所有处理数据均保存为 XLSX，没有使用 CSV。
