## 7. 每次开始工作的标准初始化

```bash
git fetch origin --prune
git status -sb
git log --graph --decorate --oneline --all -n 20
```

然后根据章节指南确定 canonical branch，从**最新远端 canonical branch**开任务分支：

```bash
git switch <canonical-branch>
git pull --ff-only origin <canonical-branch>

git switch -c task/<role>/<module>-<topic>-YYYYMMDD
```

若本地 canonical branch 已被其他 worktree 占用，可直接基于远端创建：

```bash
git switch -c task/<role>/<module>-<topic>-YYYYMMDD origin/<canonical-branch>
```

完成后先提交到任务分支，不直接 merge `main`。
