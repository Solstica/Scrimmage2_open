## Q2

参考资产：`modules/30_q2/figures/editable/origin_templates/reference_png/2.png`

必须删除旧逻辑：

- 删除 `双角度共享参数联合拟合` 作为候选主路线的判断分支；
- 不允许把共享参数联合反演重新写入主结果。

正式流程应为：

`附件1/2 -> 预处理 -> 2500--3300 cm^-1弱吸收波段 -> 10°独立多初值有界反演 + 15°独立多初值有界反演 -> 局部盆地残差竞争诊断 -> 取各角度最低残差盆地 -> 算术平均 -> d = 7.7398 μm`

冻结结果：

- 10°：7.8566 μm；
- 15°：7.6230 μm；
- 最终 SiC：7.7398 μm。

流程图中“多初值”节点不应写成“全部收敛”。正确含义是：

`多初值覆盖 -> 多个干涉级次局部盆地 -> 完整参数精修 -> 按最终残差选择主盆地`

## Q3

参考资产：`modules/40_q3/figures/editable/origin_templates/reference_png/q3_flow_reference.png`

必须删除旧逻辑：

- 删除 `η3 >= 0.1% ?` 后决定采用双光束或 Airy 的模型选择流程；
- 删除 `采用双光束模型` 作为硅正式反演路径；
- 第三束光强比不得作为硅正式模型选择器。

正式流程应拆为两条：

### Si 主路线

`附件3/4 -> 预处理 -> 双振子--Drude复折射率 -> 实角Snell + 复Fresnel/传播 -> Airy多光束反射率 -> 10°/15°分别四参数多初值反演 -> 算术平均 -> d_Si = 3.2178 μm -> Jacobian--SVD局部可辨识性诊断`

冻结结果：

- 10°：3.2480 μm；
- 15°：3.1875 μm；
- 最终 Si：3.2178 μm。

可辨识性诊断节点只用于验证，不回写主厚度。图中可简写为：

`Jacobian--SVD -> 厚度高灵敏 / N、Γe弱可辨 -> 固定振子背景具有条件性依据`

其中 11 参数扩展只做前向 Jacobian，不进行 11 参数重新拟合。

### SiC 回溯路线

`读取 Q2 最终参数 -> 计算第三束光强比 η3 -> 与 0.1% 工程参照量级比较 -> 判断高阶光束可忽略 -> 保留 d_SiC = 7.7398 μm`

这里的 0.1% 只用于回溯解释，不控制 Si 正式模型。
