## 5. Origin 图更新的编程流程

现有人工 Origin 图**要复用**，不是删掉重画。

固定流程：
1. 先读 `fix/建模手/todo/` 给出的最终逻辑；
2. 运行最终 PAPER_A 代码；
3. 导出图所需 CSV/XLSX；
4. 列名、单位、排序、样本筛选全部明确；
5. 与 frozen JSON 做一致性检查；
6. 把数据交给论文手替换进原 Origin 工程；
7. 不负责用 Python 重画一个新的“替代版美图”。

Q2 参考资产：
```text
modules/30_q2/figures/editable/origin_templates/
```

Q3 参考资产：
```text
modules/40_q3/figures/editable/origin_templates/
```

Q2 若仍缺 `.opju/.opj`，不要自己仿造 Origin 工程；先通知论文手补交原工程。

## 6. 编程手禁止事项

- 禁止为了让图“和旧图差不多”而复用旧 Excel 数值；
- 禁止只改图中文字不重算数据；
- 禁止重新实现旧共享参数联合 Q2；
- 禁止重新实现 Q3 阈值模型选择作为正式路线；
- 禁止修改论文文字来适配程序 bug；
- 禁止直接 push `main`；
- 禁止整分支合并 `feature/paper` / `feature/paper_liu`；
- 禁止未运行验证就写“PASS/稳定/鲁棒”。
